# Fourth Coast Contractors website

All files sit in one folder, so you can drag every one of them into GitHub at once.

## Files
- index.html : the website
- styles.css : design and Ohio State colors
- main.js : mobile menu
- logo.png, favicon.png : your logo

## Publish on GitHub Pages
1. Sign in at github.com and click New repository. Name it fourth-coast-contractors, set it to Public, and click Create repository.
2. Click "uploading an existing file". Open the unzipped folder on your computer, select ALL files, and drag them into the browser window.
3. Click Commit changes.
4. Go to Settings > Pages. Under Build and deployment pick "Deploy from a branch", choose main and / (root), then Save.
5. In a minute or two your site is live at https://YOURUSERNAME.github.io/fourth-coast-contractors/

## Contact form
The form opens the visitor's email app. To receive submissions directly, make a free form at formspree.io and change the form tag's action to your Formspree link.
